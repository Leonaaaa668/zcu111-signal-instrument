# 故障树与停止点

| 触发/误判 | 先区分什么 | 下一项最小检查 | 停止点与验证 |
|---|---|---|---|
| 第一次DMA/MMIO读取后挂起、RCU stall | 地址是否来自同版本XSA；控制/数据时钟；复位与DDR；是否有另一驱动占有 | 先离线画依赖和最后访问位置；更改一个已证实的启动条件后才做一次诊断 | 原地址仍阻塞则停止重试；有成功读取后仍需回读/停播验证。C01 |
| 加clk_ignore_unused仍失败 | 保留时钟不等于复位链完整释放 | 核对实际启动代码、GPIO/复位源、DDR就绪条件 | 不把EMIO95或某个RESET编号照抄到另一板卡。C01 |
| 文件大小、SHA正确却调制质量差 | 字节传输正确与DSP数学正确不同 | 独立接收匹配滤波、定时/相位约定、符号集合检查 | RRC符号/相位索引未过不能拿文件播放；数字通过后RF仍单测。C02 |
| 鼠标亮但Qt不动 | USB供电/枚举、Linux输入事件、Weston用户会话、Qt事件和绘制 | 在已确认输入事件后才对分辨率/渲染器做可回退对照 | 本项目1080p/Pixman恢复；不推断所有设备换Pixman都更快。C03 |
| 点生成后上传找不到文件 | 操作完成、生成成功和保存成功不是同一状态 | 查看生成日志、实际目录、可写性、statvfs/剩余空间、完整文件名 | 找到成功生成的实际文件才上传；/tmp能用但断电丢失。C04 |
| UI说播放成功 | 命令接受、DMA供数、DAC数字状态、RF频率功率不同 | 分层核对状态、回读和仪器，标出当前已到哪一层 | 不把TX_PLAY_COMMAND_ACCEPTED写成RF验收 |
| 1.8GHz NCO却看不到1.3GHz | NCO平移不保证后级抽取滤波保留整个ADC频带 | 计算各级带宽、实际通带；改变NCO后等待稳定并采已知信号 | 改显示坐标不能找回已滤掉的信息。C06 |
| 1GHz横轴被理解成1GHz瞬时带宽 | 13段顺序采集与同时采集不同 | 记录分段中心、每段有效区间、完整轮次和时间戳 | 不以宽横轴或单轮图宣称无缝/同时监测。C06 |
| 空接收口Marker显示奇怪频率 | Marker可指向噪声；发射接到外部仪器不等于也接到ADC | 核对接线、源开关、峰值高于噪声条件和当前采集有效性 | 先建立同一真实信号，不能先做频率补偿 |
| DAC停播后中心小尖峰仍在 | RX固有杂散/环境/数字直流等不等于DAC NCO泄漏已证实 | OFF基线、终端负载、不同接收中心、外部仪器对照 | 未定位时保留原谱，不通过隐藏bin或改曲线解决 |
| CW补偿应用到QAM/任意频率 | 参考面、RMS、PAPR、带宽与检波方法变了 | context匹配及预留点检查；必要时另建标定 | 不外推；不给未标定信号显示成可信目标dBm。C05 |
| 资源下降被算成纯优化 | 功能/点数/缓存/调试核/设计阶段是否相同 | compare-reports+真实配置证据 | 缺配置或功能变了则NOT_COMPARABLE；旧时序失败另注明。C08 |
| 新源码包能解压就说可复现 | 外部路径、遗漏约束/系数、SDK/内核不匹配 | 新目录恢复并重编译；manifest与版本回执 | 未重做的综合/镜像/冷启明确保留，不继承旧确认。C07/C08 |
| USB IQ文件导出失败 | 仪器内部存储、USB目标、格式说明、Windows可见性不同 | 核对路径/大小/文件列表；保留原始数据与设置 | 没拿到IQ则不编造星座/EVM；可暂缓次要项目并写明边界 |
| U-Boot命令在Linux shell执行失败 | ZynqMP>与root shell是不同解释器 | 先辨认当前提示符；解释命令属于哪个阶段 | 不反复重启重试错误上下文。C01记录0832 |

这些是基于项目观察的排查入口，不是每次都要执行的通用安全清单。按实际症状选择，避免不必要的复位、改配置和重复测量。
