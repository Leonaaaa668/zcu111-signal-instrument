# 设计原理与软硬件划分（报告技术材料）

平台以ZCU111/XM500为基础，将单路RF采集、分析、波形播放与本地仪器交互合为一体。面向教学和算法验证的价值在于一台设备同时提供可调信号源、频谱观测和参数实验，减少依赖上位机的开发链路，并能保留原始结果和参考比对。

接收链：ADC2.4GS/s经RFDC混频输出IQ、抽取2，PL继续抽取8到150MS/s，完成Hann/FFT/功率谱；快照bank把完整结果和序号/配置/质量/窗系数指纹一致地送入DMA，Linux模块管理内存和事务。ARM只处理谱结果、物理量、拼接与显示。N65536包524544字节，相对150MS/s的16bit I+16bit Q原始数据600MB/s大幅减轻显示链路搬运；此为结构/算术分析，不作为原始IQ持续DMA测速。

发射链：Qt在ARM生成10ms、1.2G复点/s、I16+Q16波形，48MB经PS上传到PL DDR4，回读及SHA256验证成功后才允许显式播放。MM2S/FIFO/保护模块把每拍4点送入RFDC，经插值2与DUC，DAC以2.4GS/s输出。开始/停止、欠载和静音被设计为可观察状态。

软件以Linux驱动为所有者管理DMA，不在GUI使用/dev/mem或早期裸机固定DDR地址；控制时钟/复位/DDR就绪/RFDC/overlay有明确启动顺序。Qt后台接收和最新帧邮箱隔离采集、计算、绘图，避免每次刷新重开设备和同步阻塞交互。帧序号和接收凭据用于拒绝陈旧或不完整结果。

1GHz视图通过13段NCO顺序调谐和有效区域拼接；窄带保留65536点做精细分析。Marker主页面同时显示4个测点并可求差值，峰值随有效曲线定位；RBW、视频平均及扫描时间按当前算法语义显示。

创新/特色可围绕“同板独立仪器化、可验证的DDR波形链路、分段覆盖与局部细节兼顾、带证据的标定与交付”阐述。这些是本项目集成与工程设计贡献，不宣称发明FFT或全新RFSoC器件能力。资源时序、原始实验与局限分别见hardware_performance.md、board/measurements.md和status_and_scope.md。
