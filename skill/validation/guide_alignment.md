# 技能包与指南对应

| 要求 | 本目录内容 | 检查方式 |
|---|---|---|
| 入口与适用范围 | README、SKILL、工作流 | 参数、框架、板卡和输入明确 |
| 使用方法 | 快速上手、六组提示词模板、演练 | 开发电脑执行，无硬件动作 |
| 提炼过程 | 技术案例集C01–C08 | 现象、定位、修正、结果、复用边界 |
| 可执行效果 | 检查脚本、30项行为测试、六项演练 | 正例及预期拒绝反例分开 |
| 失效条件 | 工作流、故障树和案例边界 | 不外推RF精度、迁移或等功能优化 |

公开技能包只保留工具、模板、技术总结与测试附件，不包含聊天正文及语料索引。指南另要求的协作交互材料由队伍按提交渠道单独准备，不把案例总结自动当作完整交互记录。
